# Addons

Decisión del usuario: **todos los de calidad de vida (QoL)** y **ninguno de guía de leveo**.

En Forever los addons funcionan con la misma API y las mismas restricciones que el WoW actual (retail). Los de Classic Era no tienen por qué funcionar. **Instala solo versiones marcadas como compatibles con WoW Forever** en CurseForge.

## Instalar
| Addon | Para qué |
|---|---|
| **TomTom** | Flecha de navegación. Escribe `/way <zona> <x> <y>` con las coordenadas de esta guía |
| **Forever Flight Times** | Tiempo que falta para llegar en cada vuelo |
| **Details!** | Medidor de daño (Forever ya trae uno integrado; Details! es más completo) |
| **Deadly Boss Mods** | Avisos en los jefes de mazmorra |
| **BugGrabber + BugSack** | Recogen los errores de otros addons para que no molesten |
| PP Forever | Gestión de buffs, útil en grupo |
| Gladius Reloaded | Marcos de arena para PvP (a 60) |
| DynamicCam | Cámara más dinámica (opcional) |
| EllesmereUI | Reemplazo de la interfaz (opcional) |

## No instalar (guía de leveo o de misiones)
- **Questie**, **Quest XP Tracker**, **Forever Quest Tint**: marcan misiones y rutas. El usuario no los quiere.
- Ningún addon de rutas paso a paso, como RestedXP.

## Pendiente de buscar
La lista de CurseForge no tenía ningún addon específico de cazador (felicidad de la mascota, munición o swing timer de Auto Shot), ni de bolsas o de subasta. Cuando el usuario instale el juego, busca versiones de Forever de:
- un **swing timer de Auto Shot**;
- un addon de **bolsas**;
- un addon de **subasta** (por ejemplo, Auctionator).
